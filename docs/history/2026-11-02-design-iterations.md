### 새 연구실과 자산 제작

기존 사무실 구조를 시안 구현의 제약으로 삼지 않는다. 새 연구실 장면으로 진입하며 기존 사용자 배치는 별도로 보존하고 기존 배치 화면으로 돌아갈 수 있어야 한다. runtime 연결, 대화 기록, 실제 작업 상태와 사용자 이름·아바타 설정은 재사용한다. 뒤벽 수납장, 우드·차콜 데스크, 세이지 파티션, 식물, 타일 바닥, 부드러운 빛, 사선 구도와 밝은 채팅·상하단 메뉴를 실제 3D로 구성한다.

Blender 제작 자산도 파일 생성 성공과 시안 품질 충족을 구분한다. 제작 파일·기준 이미지는 비공개로 유지하며 공개 자산은 개인 정보와 외부 의존성을 검토한다. 현재 캐릭터 제작은 품질 미달로 중단했으며, 제작 방법 조사와 구체 경로 결정 후 재개한다.

### 실제 Office 재개 범위

실제 3D와 자유 orbit을 유지한다. 기본 시안 시점으로 복원할 수 있고, 새 연구실 안에서 가구 선택·이동·회전·추가·삭제와 배치 저장·취소를 제공한다. 새 배치는 층별 별도 키에 저장하며 원래 사무실 배치를 덮어쓰지 않는다. 시안의 낮은 차콜 수납장/오크 상판, 모서리 책장, 게시판, 유리문과 연구원 왼쪽·모니터 오른쪽 구도를 기준으로 한다. 배경 이미지/2.5D 대체는 제외한다. 캐릭터는 별도 품질 검증 전까지 미완성으로 남기며, 외부 업로드·유료 생성은 별도 범위 확인이 필요하다.

새 연구실의 재질은 배포 가능한 라이선스와 출처를 기록하고 로컬 자산으로 제공한다. 저장할 수 없는 배치 편집은 안내를 보이며 초안을 유지한다. 기본 자산으로 표현할 수 없는 저장 아바타의 헤어·의상·액세서리는 기존 렌더러로 보존한다.

새 연구실의 책상 배정은 새 배치의 책상 순서와 연구원 순서로 정한다. Phase 1의 연구원 1명은 첫 책상을 사용하며, 그 책상을 삭제하면 다음 책상으로 이동한다. 기존 사무실의 책상 배정은 가져오거나 수정하지 않는다. 패브릭 파티션과 책 수납 작업대도 독립적으로 편집·저장할 수 있다. 기본 배치 개선은 저장된 배치에 자동 적용하지 않으며, 사용자가 기본 배치를 불러와 저장할 때만 교체한다. 기본 뒤 수납장의 소품 연출은 해당 기본 가구에 속하며, 새 수납장은 일반 소품으로 추가된다. 배치 편집은 가구 중심의 이동 범위를 제한하지만 벽·가구 간 충돌 회피를 보장하지 않는다.

연구실은 채팅을 열고 이벤트 콘솔을 접은 상태로 시작한다. 채팅과 콘솔은 사용자가 다시 열거나 닫을 수 있다. 기존 배치로 돌아가면 원래 가구 자산과 사용자 색을 유지한 전체 시점으로 보여 준다.

WebGL context가 중단되면 복구 안내를 표시하고 3D 화면만 다시 열 수 있다. 이 동작은 편집 초안과 대화 상태를 초기화하지 않는다. 일반 로딩 실패와 context 중단은 구분하며, 특정 브라우저 공백의 원인은 별도 관측 없이 단정하지 않는다.

기본 전경 책상은 파티션 양쪽에 작업 면을 두고, 가까운 면에 모니터·키보드 한 세트와 반대쪽에 빈 의자 두 개를 배치한다. 중앙 연구원의 책상은 모니터 두 대와 기존 좌석을 유지한다. 이 책상의 기본 메시 연출과 새 기본 배치 좌표는 구분한다. 저장된 배치의 가구 좌표는 자동으로 바꾸지 않는다. 중앙 연구원의 책상 배정과 사용자 추가 책상의 동작은 유지한다.

책장 수납물은 상단 덮개 아래에 둔다. 차콜 가구의 금속 재질은 명시적으로 선택한 수납장·기둥·프레임에 적용하며 종이·목재·벽에 일괄 적용하지 않는다. 반복되는 식물 잎과 줄기는 개별 색·형태를 보존한 인스턴스 메시로 구성한다.

목재 표면은 출처·라이선스가 기록된 로컬 CC0 오크 결 색상·법선·거칠기 맵을 방 안에서 공유하고, 실내 상판처럼 결 대비를 낮추며 장면 해제 시 정리한다. 모니터 지지대는 기둥·관절·후면 브래킷으로 구성하며 각 화면을 받친다. 소품과 화면의 배치는 책상 배정과 사용자 저장 좌표를 바꾸지 않는다.

실내 조명은 주광과 보조광의 역할을 구분하고 가구 아래 접지 그림자를 제공한다. 뒤벽과 왼쪽 벽은 천장선에서 내려오는 그림자 없는 따뜻한 면광으로 아이보리 톤을 유지하며, 바닥은 따뜻한 회색 타일로 표현한다. 모니터 받침과 파티션은 서로 관통하지 않도록 높이 간격을 두며 지지대 연결을 유지한다.

책상 다리는 상판 아래 가로대와 바닥 가로대가 이어진 닫힌 철제 프레임이며, 의자 등받이는 앉는 쪽으로 오목한 곡면이다. 칸막이 천은 고운 직조와 섞인 실 색의 질감과 미세 요철을 가진다. 작업대의 하부 수납은 서랍 앞면·손잡이·지지부가 구분되고 상판 소품은 파티션에 모두 가려지지 않게 구성한다. 공유 전경 책상으로 연구원이 이동하면 실제 착석 면의 모니터·키보드·마우스를 표시한다. 이 변화는 연구원 배정에 따른 장면 표현이며 저장 좌표나 런타임 상태를 변경하지 않는다.

상판 소품의 단단한 본체는 기본 배치와 공유 좌석 사용 시에도 고정 파티션·입력 장치와 간격을 두어 배치한다. 이 간격은 가구 내부 모델의 구성에 관한 것으로, 사용자가 편집한 다른 가구와의 충돌 회피를 뜻하지 않는다.

사무실 3D 장면의 글자(기존 배치 화면의 이름표·말풍선·기기 표시 포함)는 기본으로 라이선스가 포함된 로컬 한글·라틴 글꼴을 사용해 글꼴을 외부에서 받지 않는다. 글꼴에 없는 문자(예: 실시간 메시지의 이모지)는 이 보장에서 제외한다. 새 연구실 벽의 영문 로고 두 줄은 라이선스가 포함된 로컬 글꼴을 사용한다. 현재 영문 로고를 그리기 위해 외부 글꼴 서비스에 연결하지 않는다. 문구가 달라지면 로컬 글꼴의 글리프 지원을 재확인한다.

연구실 식물은 연결된 가지의 넓은 잎과 수납장·선반 가장자리에서 늘어지는 덩굴을 구분한다. 원형 화분은 흙보다 높은 테두리를 가지며, 이 장면 디테일은 기존 가구 배치·선택·저장 형식과 캐릭터 자산을 변경하지 않는다.

기본 수납장·선반의 덩굴은 가구 앞 가장자리를 넘은 뒤 아래로 늘어지며, 잎이 해당 앞판이나 선반 기둥을 통과하지 않도록 구성한다.

## 후속 2D — 연구실 1층 2D 시안 (공개 앱 미통합)

3D 결과가 시안에 못 미쳐, 2026-10-24부터 사용자 승인으로 연구실 1층을 2D 아이소메트릭 시안으로 다시 만들고 있다. 시안은 레포 밖 비공개 디자인 폴더에 후보별로 보존한다. 각 후보는 독립 실행 페이지(로컬 자산만 사용)이며, 공개 앱(`/office`)과 Labs Runtime에는 연결하지 않는다. 사람의 움직임은 모의 상태이다.

2026-10-29 후속 요청부터 인물 동작의 목표는 상용 서비스에 사용할 수 있는 품질이다. 개인용이라 허용했던 부자연스러운 자세·비례 변화·반복감을 개선 대상으로 삼는다. 기능 회귀 통과와 실제 화면에서의 자연스러움은 별도로 검토하며, 상용 출시 준비 완료나 실제 에이전트 연동 완료로 간주하지 않는다.

- 2D-1 (floor-18h, 독립 검토 완료) 누가 봐도 이상한 가구 배치만 최소로 고친다. 사용자 요청: "그래도 누가봐도 가구 배치가 이상한것들은 고쳐야해". 현재 2D 스타일과 방 크기, 인물·좌석, 동선, 카메라, 상태와 애니메이션은 유지한다.
  - 독립 검토석의 1.2 m 책상에는 모니터 한 대만 두어 상판 안에 들어가게 한다.
  - 회의실 화이트보드는 앉은 사람이나 좌석에 가려지지 않게 왼쪽 유리벽 안쪽에 붙인다. 원래 그림은 한 방향만 있어 그 벽에 둘 수 없으므로, 기존 팔레트로 그린 얇은 사각 판(차콜 테두리와 흰 면)으로 바꾼다. 충돌하지 않으며 회의실 출입구는 비워 둔다.
  - 인프라 유리 칸막이는 유지한다.
- 2D-2 (floor-18i, 독립 검토 완료) 사용자가 지정한 인프라 옆 갈색 2문 수납장의 방향을 맞춘다. 생성 그림 자체의 투영이 방과 달라 벽에 대해 돌아가 보이므로, 같은 차지 면적과 높이로 기존 차콜·목재 팔레트의 코드 표현으로 바꿔 벽과 같은 축에 두고 문이 실내를 향하게 한다. 다른 가구·인물·좌석·동선·카메라는 유지한다.
- 2D-3 (floor-18j, 사용자 형상 검토에서 실패. 2D-4로 대체) 출입구 옆 음료대의 방향을 맞춘다. 사용자가 지정한 대상이다. 생성 그림의 투영이 방과 달라 뒤 칸막이에 대해 돌아가 보이므로, 같은 그림을 화면 변환과 잘라내기만으로 재투영한다. 세로선을 수직으로 두고 앞면은 벽 축, 옆면은 깊이 축을 따르게 하며, 목재 질감과 상판 소품은 그대로 둔다. 차지 면적, 충돌, 동선·좌석·인물, 다른 가구는 유지한다.

- 실제 24초 시퀀스는 벽시계 약 24.16초에 종료했다. 정적 메시 합침과 그림자 계산 축소 후 렌더 호출은 31개였다. 자동화 환경은 소프트웨어 WebGL이며 프레임 간격 중앙값 68.5ms, p95 115.1ms로 원활한 성능 기준은 충족하지 못했다. 실기기 GPU·다른 브라우저·전체 연구실 규모 성능은 미검증이다.
- 기본 동작 연결과 로컬 조정 가능성을 확인한 검증용 결과이다. 기존 손그림과 같은 그림체, 성인 연구원 인상, 세밀한 관절 변형·보행 접지·정확한 키 입력 품질은 완성 판정하지 않는다. 전체 자산 교체나 제품 통합은 별도 후속 범위이다.
